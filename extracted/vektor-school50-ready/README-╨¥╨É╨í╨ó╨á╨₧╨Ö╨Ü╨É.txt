ВАЖНО: ЭТО ЕЩЁ НЕ ЗАПУЩЕНО НА NETLIFY
------------------------------------
Файлы подготовлены, но автоматический сбор и панель не заработают на опубликованном сайте,
пока архив не будет развёрнут как Netlify-проект с функциями и не будут заданы переменные окружения.
Сам сайт и Supabase из этого архива автоматически не изменяются.

ПЕРЕМЕННЫЕ NETLIFY
------------------
Открой Netlify → сайт vektor-school50 → Site configuration → Environment variables.
Добавь переменные из файла .env.example:

Обязательные:
- SUPABASE_URL — уже указан в примере.
- SUPABASE_ANON_KEY — публичный publishable key из текущего index.html.
- SUPABASE_SERVICE_ROLE_KEY — секретный service_role key из Supabase → Project Settings → API Keys.
  Выбирай legacy service_role secret/JWT, если он доступен. НИКОГДА не вставляй его в index.html.
- NEWS_ADMIN_PASSWORD — придумай отдельный длинный пароль для админки.
- NEWS_SESSION_SECRET — случайная строка не короче 32 символов.
- TELEGRAM_BOT_TOKEN — токен @VektorSchoolNewsBot из BotFather.
- TELEGRAM_WEBHOOK_SECRET — случайная строка из латинских букв, цифр, дефиса и подчёркивания.

Не присылай секретные ключи и токены в чат. Вставляй их только в защищённые переменные Netlify.
Не добавляй файл .env с настоящими секретами в ZIP, Git или публичную папку сайта.

ПУБЛИКАЦИЯ НА NETLIFY
---------------------
1. Сначала сохрани резервную копию текущего сайта.
2. Разверни весь проект из корня архива как Netlify-проект: netlify.toml, папку public и папку
   netlify/functions должны находиться рядом. Папка public — это опубликованный сайт, а папка
   netlify/functions остаётся вне публичной части, чтобы исходники backend не раздавались посетителям.
3. Если текущий сайт развёрнут через Git, обнови файлы в репозитории и сделай deploy.
   Если он развёрнут вручную через Netlify Drop, не загружай только public: так функции не попадут
   в deploy. Для backend нужно подключить GitHub-репозиторий к Netlify или выполнить deploy через
   Netlify CLI с корнем этого проекта.
4. После добавления переменных окружения запусти новый deploy.
5. Открой https://vektor-school50.netlify.app/admin.html и войди по NEWS_ADMIN_PASSWORD.
6. Нажми «Подключить Telegram-бота». Бот уже добавлен администратором в @vektor_esports,
   поэтому Telegram сможет присылать новые посты этого канала через webhook.
7. Для @vektor_public ежедневный сбор читает публичную веб-ленту t.me/s/vektor_public;
   администраторские права на этот канал боту не нужны, если публичная веб-лента доступна.

КАК РАБОТАЕТ МОДЕРАЦИЯ
----------------------
- Сборщик запускается ежедневно в 06:00 UTC.
- Найденные публикации сохраняются со статусом pending.
- Pending-публикации не отображаются на основном сайте.
- После нажатия «Одобрить» публикация появляется на сайте.
- При одобрении 31-й публикации самая старая одобренная удаляется; остаются последние 30.
- Отклонённые публикации на сайт не попадают.

ПРОВЕРКА ПОСЛЕ ПУБЛИКАЦИИ
-------------------------
- /api/news должен возвращать массив только одобренных публикаций.
- /admin.html должен открывать форму входа.
- После входа список «На проверке» должен показывать pending-публикации.
- Одобренная новость должна появиться в ленте сайта.
- Существующее голосование CS2 должно продолжить работать как раньше.

Если панель сообщает об ошибке конфигурации, сначала проверь переменные окружения Netlify.
